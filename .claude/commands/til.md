`CLAUDE.md`의 **「TIL 자동 작성 워크플로 (`작성완료`)」** 절을 그대로 수행한다.

입력: $ARGUMENTS

입력 확보 순서:

1. `$ARGUMENTS`가 파일 경로면 그 파일을 읽는다.
2. `$ARGUMENTS`가 본문이면 그대로 사용한다.
3. 비어 있으면 **직전 대화에서 사용자가 작성한 내용**을 사용한다.
4. 그래도 없으면 그때만 내용을 요청하고 중단한다.

이후 절차(내용 보존 원칙, 유형 판정, 제목 / Category / Tag / 파일명 결정, Markdown 정리,
관련 글 연결, Build 검증, 보고 형식, Commit 규칙)는 모두 `CLAUDE.md`를 따른다.
이 파일에 규칙을 중복해서 적지 않는다.
