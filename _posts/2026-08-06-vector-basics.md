## 1. 📖 개요

> 📌 **왜 필요한가** · 크기는 달라도 방향이 같은 두 벡터를 "같다"고 다뤄야 할 때가 있다.
{: .prompt-tip }

정규화는 벡터의 크기를 버리고 방향만 남기는 연산이다. 노름·단위벡터와 함께,
수학의 '차원'과 NumPy의 '축'이 다른 말인 이유까지 정리한다.

---

## 2. 💡 핵심 개념

### 스칼라 · 벡터 · 행렬

- **정의:** 스칼라는 숫자 하나로 표현되는 단일 값, 벡터는 여러 숫자를 순서대로 나열한 묶음, 행렬은 행과 열의 2차원 격자 형태로 배열한 것이다.
- **핵심 포인트:** 스칼라 → 벡터 → 행렬은 데이터를 담는 차원이 하나씩 늘어나는 관계다.

### 수학의 '차원' vs NumPy의 '축'

같은 값을 부르는 말이 두 분야에서 다르다. 헷갈리기 쉬운 지점이다.

```python
v = (-4, 5)
# 수학적 : 2차원 벡터. 독립된 성분이 2개.
# numpy  : 1차원 배열.

u = np.array([2, -1, 7])
print(u.shape)      # (3,)
# 수학적 : 성분이 3개인 3차원 벡터
# numpy  : 축이 하나인 1차원 배열
```

> 💡 **한 줄 정리** · 수학의 차원은 벡터의 성분 개수, NumPy의 축은 배열의 중첩 단계다.
{: .prompt-info }

---

## 3. 🔍 이해하기

### 벡터의 덧셈

두 벡터는 같은 위치의 성분끼리 더한다. 기하학적으로는, 첫 번째 벡터의 끝에
두 번째 벡터를 이어 붙였을 때 도착하는 위치가 합벡터다.

### 스칼라 곱

모든 성분에 같은 숫자를 곱하는 연산이다. 기하학적으로는, 방향은 그대로 두고
벡터의 길이를 늘리거나 줄인다.

### 노름 (norm)

벡터의 크기(길이)다. 피타고라스 정리로 계산한다 — L2 노름(유클리드 노름).

### 정규화와 단위벡터

단위벡터는 노름이 1인 벡터다. 원래 벡터를 자신의 노름으로 나누면 된다.

벡터 `(3, 4)`를 `(0.6, 0.8)`로 정규화하면:

| 항목 | 정규화 전 | 정규화 후 |
| --- | --- | --- |
| 벡터 | `(3, 4)` | `(0.6, 0.8)` |
| 길이 | 5 | 1 |
| 방향 | 유지 | 유지 |
| 성분 비율 (3:4) | 유지 | 유지 |

> ⚠️ **정규화 전에 반드시 확인할 것: 노름이 0인지.** 영벡터는 0으로 나누게 된다.
{: .prompt-warning }

## 4. 🧪 코드 / 실습

벡터 덧셈:

```python
a = (1, 2)
b = (3, 1)
# a + b = (1+3, 2+1) = (4, 3)
```

스칼라 곱:

```python
v = (2, 3)
# 2v = (2*2, 2*3) = (4, 6)
```

노름:

```python
import numpy as np

v = np.array([3, 4])
norm_v = np.linalg.norm(v)   # 5.0
```

정규화:

```python
v      = np.array([3, 4])
norm_v = np.linalg.norm(v)   # 5.0
unit_v = v / norm_v          # array([0.6, 0.8])
```

성분이 0이어도 영벡터가 아니면 정상적으로 정규화된다:

```python
# 벡터 (0,5)를 정규화하면?
v      = np.array([0, 5])
norm_v = np.linalg.norm(v)   # 5.0  (성분 하나가 0이어도 노름은 0이 아니다)
unit_v = v / norm_v          # array([0., 1.])
```

<details markdown="1">
<summary><strong>Q.</strong> 벡터 [3,4]와 [6,8]을 정규화하면 모두 [0.6, 0.8]이다. 정규화를 통해 사라지는 정보와 유지되는 정보는 각각 무엇인가?</summary>

- **사라지는 정보** : 벡터의 원래 길이(크기) → 어느 벡터가 더 길었는지 알 수 없다
- **유지되는 정보** : 벡터가 가리키는 방향 → 두 벡터가 같은 방향이라는 정보는 남는다

</details>

<details markdown="1">
<summary><strong>Q.</strong> 벡터를 정규화하기 전에 반드시 확인해야 하는 조건은 무엇인가?</summary>

벡터의 노름이 0인지. 영벡터는 0으로 나누게 되어 `nan`이 된다.

</details>

## 5. ✅ 핵심 정리

- **스칼라 → 벡터 → 행렬** : 데이터를 담는 차원이 하나씩 늘어나는 관계다
- **차원 vs 축** : 수학의 차원은 벡터의 성분 개수, NumPy의 축은 배열의 중첩 단계다
- **정규화** : 벡터의 크기를 버리고 방향만 남기는 연산 — 방향은 유지되고 길이만 1로 바뀐다
- **주의** : 정규화 전에는 항상 노름이 0인지 확인해야 한다 (영벡터는 0으로 나누게 된다)

## 6. 🧠 핵심 기억 카드

<details markdown="1">
<summary><strong>펼쳐서 확인</strong></summary>

`np.array([2,-1,7]).shape`가 `(3,)`인 것을 처음에 "3차원 배열"로 읽었다.
수학의 **차원**(성분 개수 = 3)과 NumPy의 **축 개수**(= 1)는 서로 다른 말이다.
`shape`의 원소 개수가 축 개수이고, 각 원소의 값이 그 축의 길이다.

</details>
